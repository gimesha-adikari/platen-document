# 0.1.10rc1 release candidate

This unpublished release candidate carries the bounded POSIX subprocess runner
already present on the SDK default branch. It drains stdout and stderr
concurrently, enforces one combined output budget and a timeout, checks
cancellation while reading, and terminates/reaps the owned process group on
success and failure.

The version is a candidate identifier for source review and local installation.
It has not been published to PyPI or another package registry. Consumers must
not request this version from a registry until a separately approved release
publishes the exact reviewed source.
