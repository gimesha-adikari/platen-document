# Prototype iteration notes

These notes preserve issues found and corrected before the final Phase 1 run. The source-derived intermediate PDFs and crops remain in the local ignored `artifacts/private-source/` directory; only the final candidate and final comparison are referenced in `TEST_RESULTS.md`.

1. **Test-first RED:** the first test collection could not import the not-yet-created prototype module. After adding an empty API shell, the three mask/refusal behavior tests failed as expected; the eight end-to-end checks failed against `NOT_IMPLEMENTED`. No production files were involved.
2. **Implementation error:** the first colored-pixel detector revision referenced a removed local variable and caused eight test failures. The count now uses the RGB buffer length; the colored-stamp and table-rule tests pass.
3. **Border fixture geometry:** the initial table rule sat just outside the OCR target and the detector was too sensitive to natural vertical letter strokes on a skewed scan. The rule now crosses the target; detection uses a predeclared 1.5 pt inspection pad and a stricter line-coverage threshold. A separate 1 pt band remains the maximum edited region.
4. **Initial replacement appearance:** the first Helvetica draft was too light and small. Visual comparison led to a darker Times-Bold Base14 approximation sized from the frozen OCR box. This remains an approximation, not source-font recovery.
5. **Source-derived residual:** the first actual-page render left a faint remnant which OCR classified as `~~`. The fixed repair mask now covers the target box plus its predeclared 1 pt antialias band, and candidate OCR validation rejects any extra token in that band. The final source run reports one `hello`, zero `Ministry`, and zero unexpected target tokens.
6. **Threshold trial:** reducing the contrast margin to 14 removed the residual but over-smoothed the scan paper. That version was rejected. The final margin is 32, with only the 1 pt mask expansion retained; the synthetic oracle test reports MAE 1.3634 after repair.
7. **Test invocation environment:** a final bare `pytest -q -p no:cacheprovider` attempt selected system Python 3.14, where PyMuPDF is not installed, and failed during collection. The documented repository `.venv` invocation is the supported test environment; the targeted suite and full suite were rerun there and passed.

Final verification after these corrections: in the repository `.venv`, the isolated prototype suite passes 12/12; the complete SDK suite passes 443 tests with one existing skip; independent Poppler/qpdf comparison passes. The bare system-Python invocation failure is documented above. The real source background beneath the printed word has no oracle, so local texture reconstruction remains a visual limitation rather than a mathematically exact restoration claim.
